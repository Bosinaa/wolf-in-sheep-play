# Волк в овечьей шкуре

Браузерная игра про работу рекрутёра: через тебя идёт поток кандидатов, часть резюме накручена — приписанные годы, чужие статьи, компании, которых нет в реестре. Нужно читать вкладку против вкладки и обводить красным то, что не сходится.

**▶ Играть: https://bosinaa.github.io/wolf-in-sheep-play/**

## Как играется

1. Нажимай на строки документов и реплики интервью, которые противоречат друг другу — отмеченное обводится красным.
2. Как только отмечено две строки, они сверяются. Расхождение настоящее — оно уходит в подтверждённые; нет — сгорает одна из четырёх сверок за кандидата.
3. **Проверки** (звонок рекомендателю, ЕГРЮЛ, реестр сертификатов, авторство файлов) открывают то, чего нет в папке. Лимит общий на день.
4. Пропустишь накрутчика — он выйдет на работу. Откажешь честному без основания — жалоба на предвзятость. Любая из двух шкал доводит до увольнения.

41 кандидат, 7 дней, сквозной сюжет про фабрику резюме.

## Технически

- Статика без зависимостей и без сборщиков: HTML + CSS + один файл движка.
- Работает офлайн после первого открытия (service worker), ставится на домашний экран телефона.
- Прогресс хранится локально в браузере, ничего не отправляется на сервер: аналитики и трекеров нет.
- Портреты кандидатов подгружаются по мере необходимости, поэтому первый экран весит около 90 КБ.

В этом репозитории лежит только собранная игра. Исходники (пайплайн сборки, движок, данные кейсов) не публикуются, чтобы ответы к кейсам не читались напрямую.
